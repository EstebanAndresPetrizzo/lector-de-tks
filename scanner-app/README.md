# Lector de tickets

Abrí `INICIAR LECTOR.cmd` y luego visitá http://localhost:4173. La aplicación no sube los tickets: usa la webcam y genera el Excel en tu computadora.

Para registrar una compra, apuntá al QR de AFIP del comprobante. El QR contiene fecha, CUIT, importe, punto de venta y número de comprobante; seleccioná el concepto correcto y la compra se agrega al registro. Al descargar, el archivo conserva las columnas y el formato de `Registro Deducciones Diciembre 2025.xlsx`.
